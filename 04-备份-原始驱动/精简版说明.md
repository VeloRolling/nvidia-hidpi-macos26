# 精简版说明（25MB 以内）

这个包为控制体积做了裁剪，**功能没变**，只是少了一份冗余备份。

## 与完整版的唯一差别

去掉了一个文件：

```
04-备份-原始驱动/backup-原始NVRM-2.4.3/AuxiliaryKernelExtensions.kc.orig   18MB
```

它是完整版里那份「原始辅助内核集合」的整体快照。剩下的备份仍然齐全：

```
04-备份-原始驱动/backup-原始NVRM-2.4.3/NVRM.kext.orig    16MB  原始 2.4.3 驱动
02-驱动NVRM-planE/NVRM.kext                              16MB  打过 planE 的驱动
```

## 对回滚的影响

`03-脚本/回滚NVRM.command` 已改成自适应：

- 有 `AuxiliaryKernelExtensions.kc.orig` → 先覆盖集合，再 `kmutil create` 重建（完整版行为）
- 没有（本精简版）→ 直接用 `kmutil create` 从 `/Library/Extensions` 重建

结果一样：集合里装的是**原始 2.4.3** 驱动，planE 补丁被撤销。只是不再有「重建失败就退回旧集合」这一层兜底。

## 想要那份备份怎么补回来

原始驱动安装时在 `/Library/NullMoth/` 下留了若干 `backup-<时间戳>/` 目录，里面就是当时的集合与 kext。任选一个拷出来即可：

```bash
ls /Library/NullMoth/
sudo cp -R "/Library/NullMoth/backup-<时间戳>" ~/Desktop/AuxKC-备份
```

或者在你当前系统上直接导出正在用的集合（如果你现在跑的就是官方 2.4.3）：

```bash
sudo cp /Library/KernelCollections/AuxiliaryKernelExtensions.kc \
        ~/Desktop/AuxiliaryKernelExtensions.kc.orig
```

## 体积账

| 项目 | 原始 | 压缩后 |
|---|---|---|
| AuxKC 快照 | 18.16MB | 11.14MB |
| 原始 NVRM.kext | 16.00MB | 10.86MB |
| planE NVRM.kext | 15.91MB | 10.85MB |
| 其余全部（脚本/文档/diff） | 0.13MB | 0.05MB |

Zip 对 Mach-O 二进制只能压到约 68%，所以「33MB → 25MB 以内」必须动这三个文件之一，没有纯压缩的解法。
